## P0｜功能直接不能用

### A1. 画布「素材节点」本地上传 100% 失败 —— 字段名写错（已定位到行）

**现象**：素材节点点「上传图片」→ 选完文件 → 报「上传失败，请重试」。

**证据（浏览器控制台原文）**：
```
[ERROR] [AssetNode] 上传失败 Error: 上传未返回地址
    at handleFileChange (src/views/workflow/components/nodes/AssetNode.vue:76)
```

**根因**：同一个上传接口，两个节点读的字段不一样。

| 位置 | 读的字段 | 结果 |
|---|---|---|
| `AssetNode.vue:76` | `uploaded.fileUrl` | **永远 undefined** → 抛「上传未返回地址」 |
| `ImageNode.vue:112` | `uploaded.publicUrl` | 正常（实测多次成功） |

而上传接口的返回类型是（`src/api/storage.ts`）：
```ts
export interface UploadedStorageFile {
  filePath: string
  relativePath: string
  publicUrl: string   // ← 只有这个，没有 fileUrl
  filename: string
  mimeType: string
  size: number
}
```

**修法**：`AssetNode.vue` 改读 `publicUrl`（一行）。同时建议把这类「多节点各写一份上传处理」收敛成一个工具函数，
否则还会有第三个节点再踩一遍。

### A2. 画布「素材库」选择器被裁到不可用（能看到素材，但选不到）

**现象**：素材节点点「从素材库选择」→ 弹出选择器，但只能看到前几张。

**实测证据**：

| 指标 | 值 |
|---|---|
| 选择器容器 | **194 × 146** px |
| 内层列表 | clientHeight 180 / scrollHeight 180 / `overflow: hidden` |
| 素材图 | 25 张，每张 **54 × 54** |
| 按宽度排版 | 3 列 → 25 张需 ~9 行 ≈ 520px 高 |

容器高度只有 146 且**不可滚动**，所以除前几张外**用户既看不到也选不到**。
截图：`~/artifacts/finding-canvas-asset-picker.png`

**修法**：容器给固定可用高度（如 `min(60vh, 420px)`）+ `overflow-y: auto`；网格列宽自适应；
搜索框已存在（「搜索素材名」）可与列表联动。

## P1｜看着能点、点了没反应（假入口）

### B1. 首页作品详情面板：「做同款」「用作参考图」是死元素

**证据**：两者都是 `<p class="operation-text">`，`cursor: pointer`，
但**没有可点的祖先元素、没有 handler**：

| 文案 | 标签 | cursor | 可点祖先 |
|---|---|---|---|
| 做同款 | `p.operation-text` | pointer | **null** |
| 用作参考图 | `p.operation-text` | pointer | **null** |

对比：同面板的「使用提示词」是 `<button>`，点了**真的**把提示词填进输入框（实测通过）。

### B2. 详情面板「图片模型」显示的是尺寸

「图片模型」这一行的值是 **`1536x1024`**（尺寸），不是模型名。字段取错或标签写错，二者必有一。

### B3. 详情面板创建时间显示裸 ISO 串

面板直接渲染 `2026-09-22T15:00:23.984Z`，未做本地化格式化。

- 已修：服务端限流 用户 3→**8**、厂商 8→**20**、技能 4→**12**、提交限流 6→**20**（运行时设置已生效）。
