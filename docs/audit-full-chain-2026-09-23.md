## 一、已修复（附验证方式）

### ✅ A1. 画布素材节点本地上传 100% 失败 —— 字段名写错

**证据（浏览器控制台原文）**
```
[ERROR] [AssetNode] 上传失败 Error: 上传未返回地址
    at handleFileChange (src/views/workflow/components/nodes/AssetNode.vue:76)
```

**根因**：同一个上传接口，两个节点读的字段不同。

| 位置 | 读的字段 | 结果 |
|---|---|---|
| `AssetNode.vue` | `uploaded.fileUrl` | **永远 undefined** → 抛错 |
| `ImageNode.vue` | `uploaded.publicUrl` | 正常 |

而 `UploadedStorageFile`（`src/api/storage.ts`）**只有 `publicUrl`，没有 `fileUrl`**。

**修法**：改读 `publicUrl`（并留注释说明）。**验证**：浏览器里选文件上传 → 节点出现图片 + 文件名，刷新后仍在 ✓。

### ✅ A2. 素材库选择器小到不可用

**实测**：选择器容器 **194×146**；25 张素材每张 54×54；按宽度只能排 3 列 → 需 ~9 行 ≈520px；
可视区仅 **103px** 且 `overflow: hidden`（**注：我第一轮说「不可滚动」是量错元素，实际 `overflow-y:auto` 可滚**，
真正的问题是窗口太窄太矮）。

**根因**：选择器被 `inset: 8px` 关在节点内部，而素材节点自身只有 **260×200** ——
按 LibTV 工具类节点规范应为 **350×350**。

**修法**：① 节点尺寸改由 `config/node-size.ts` 统一固定（350×350）；② 选择器移出卡片、
允许超出节点边界，尺寸 `min(420px,72vw) × min(400px,60vh)`；③ 缩略图 56→84px。
**验证**：截图确认 4 列 × 5 行、约 20 张一眼可见 ✓。

**附带修掉**：素材节点此前**被图片自然尺寸撑爆** —— 上传一张 1200×800 后节点变成 **1202×839**
（卡片只有 `min-height` 没有固定高度）。固定尺寸后实测 350×350 ✓。

### ✅ B1. 首页作品详情面板：「做同款」「用作参考图」是死元素

**证据**：两者都是 `<p class="operation-text">`，`cursor:pointer`，
**没有可点祖先、没有 handler**（同面板的「使用提示词」是 `<button>`，实测可用）。

**根因**：`HomeDetailModalFrom.vue` 是从别的站点扒下来的**静态结构**（类名是 `operation-button-ZGVDtf`
这类哈希串），这两个块只有 `tabindex="0"`，emits 里也没有对应事件。

**修法**：补 `@click`/键盘事件 + `role="button"`，并接上真实行为 ——
「做同款」= 用同款提示词与画幅直接提交一次生成（走 `ContentGenerator.submitDraft`）；
「用作参考图」= 把当前大图加进内联生成器的参考图并展开。
**验证**：「用作参考图」实测生成器展开 724×210 且带 1 张参考图 ✓。

### ✅ B2/B3. 详情面板参数是 mock 值、时间显示裸 ISO

**证据（修前）**：面板显示 `图片模型` / `1536x1024` / `2026-09-22T15:00:23.984Z`。
**根因**：`DiscoverContent.vue` 的映射里 `modelLabel: item.modelLabel || '图片模型'`、
`aspectRatioLabel: item.aspectRatio`（把尺寸当比例）、`createDate: item.createdAt`（裸 ISO 直接上屏）；
`home.vue` 与面板 props 另有一批 mock 兜底（`'图片 4.1'` / `'9:16'` / `999` / `'2026-04-16'`）。

**修法**：去掉所有 mock 兜底（没有就为空 → 面板整行不渲染）；比例用 `describeAspectRatio` 换算（`1536x1024`→`3:2`）；
时间在面板里格式化。**验证**：面板不再出现裸 ISO 与 mock 模型名，比例显示 `1:1` ✓。

### ✅ A3（我自己引入又修掉的严重问题）首页静默退回演示数据

**证据**：首页该请求 `200` 且返回 **25 条**，但页面渲染的是 **41 条外部演示数据**；控制台：
```
[WARNING] 读取首页瀑布流失败，继续使用本地 JSON 数据。 ReferenceError: describeAspectRatio is not defined
```

**根因**：我在 B2 的改动里加了 `describeAspectRatio(...)` 调用却**漏了 import**
（我那段脚本的守卫条件里恰好把这个名字写进了注释，于是跳过 import）；构建/类型检查**都没报**，
运行时抛错 → 组件 catch → 静默用本地 JSON 兜底 → **用户看到的就是演示数据里的 mock 参数**。

**修法**：补 import。**验证**：首页 feed 从「41 条外部演示数据」变为「**25 条自有作品**」✓。

> ⚠️ **工具盲区（值得记）**：`vue-tsc` 对该文件里「使用了未 import 的标识符」**没有报错**，
> 是运行时才暴露的。以后凡是新增函数调用，必须同时看运行时控制台，不能只看类型检查。

### P3-1. 批量生成缺少「排队中」状态（用户点名的 50 分钟焦虑）

**现状**：服务端有并发上限与排队，但**前端只显示转圈**，用户不知道排第几、还要多久。
**方案**：节点/任务列表显示「排队中（前面 N 个）」+ 已等待时长 + 预计时间；
超过阈值给「继续等待 / 取消」两个出口。数据可从 `/api/generation-tasks` 的队列信息取。

### P3-2. 「重试要重新输入提示词」——仍未复现到具体入口

画布图片节点的失败态已给「重试/放弃」，且重试会**从任务记录取回原文**（不走 `composeFinalPrompt`）。
用户遇到的很可能是**另一个入口**（视频节点 / 生成历史 / 首页对话）。需用户指认或继续扫。

### P4-1. 首页 hero 轮播仍用第三方签名 CDN

→ **2027-01-22 过期**，到期必裂；且不是我们的资源。
**方案**：换成本地图（已有 `public/banner/*.png`，或从我方生成图里选 3 张横构图）。
